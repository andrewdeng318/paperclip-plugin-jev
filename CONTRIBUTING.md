# Contributing

Contributions are welcome.

1. Open an issue that explains the problem or proposed change.
2. Create a focused branch.
3. Add or update tests.
4. Run the verification commands.
5. Open a pull request with the behavior change, verification evidence, and security impact.

```bash
pnpm install
pnpm typecheck
pnpm test
pnpm build
```

Never include API keys, private issue content, or local Paperclip data in an issue, commit, test fixture, or pull request.
